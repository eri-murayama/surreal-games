## ざっくりした流れ

1. Claude Codeをインストールする
2. 「こんなサイトを作って」とAIに伝える
3. AIがコードを書いてくれる
4. 表示を確認して「ここ変えて」と伝える
5. 2〜4を繰り返す
6. GitHub Pagesで公開する

やっていることは基本的に**「AIとチャットしているだけ」**です。

## 一番困ったこと：英語が読めない

Claude Codeは海外のツールなので、エラーメッセージや説明が英語で出てくることがあります。

プログラミング未経験 × 英語読めない。ダブルパンチです。

最初は頑張って読もうとしましたが、すぐに諦めました。

そしてClaude Codeにこう伝えました：

AIって、こちらの理解度に合わせてくれるんです。「わからない」と正直に言うのが一番のコツだと、この時学びました。

## Step 1：Claude Codeを使えるようにする

### 1-1. アカウント登録

まず、Anthropicのサイトでアカウントを作ります。

1. https://claude.ai にアクセス
2. 「Sign up」からアカウント作成（Googleアカウントでも可）
3. 有料プラン（Max）に加入する
   - 月額約15,000円
   - クレジットカードが必要です

### 1-2. Claude Codeのインストール

Claude Codeはパソコンのターミナル（黒い画面）で動くツールです。

怖く見えますが、やることは簡単です：

1. **VS Code**（無料のコードエディタ）をインストール
   - https://code.visualstudio.com/ からダウンロード
   - 「なにこれ？」と思うかもしれませんが、メモ帳の高機能版だと思ってください
2. VS Codeの拡張機能から**Claude Code**を検索してインストール
3. ログインする

これだけです。

### 1-3. 最初に伝えるべきこと

Claude Codeを起動したら、最初にこう伝えてください：

```
私はプログラミング完全未経験です。
専門用語は使わないでください。
何かする前に必ず日本語で説明してから確認してください。
```

**これ超重要です。** 最初にこれを言うかどうかで、その後の体験がまったく変わります。

## Step 2：サイトの骨組みを作る

### 最初のプロンプト（コピペOK）

```
ゲームを紹介するウェブサイトを作りたいです。

サイト名：シュールゲームス
コンセプト：意味不明でかわいいゲームを作るスタジオ

以下のセクションを持つ1ページのサイトを作ってください：
- トップ（サイト名とキャッチコピー）
- ゲーム一覧
- ギャラリー
- スタジオ紹介
- お問い合わせ

シンプルでかわいいデザインにしてください。
```

AIがコードを書き始めます。「ファイルを作成していいですか？」と聞かれたら「はい」と答えてください。

### ポイント：完璧を目指さない

最初から完璧なサイトは出てきません。でも大丈夫。**後からいくらでも修正できます。**

まずは「なんか出てきた！」という感動を味わってください。

## Step 3：見た目を調整する

骨組みができたら、見た目を自分好みに変えていきます。

### 使えるプロンプト集

**色を変えたい時：**
```
サイト全体の色をもっとパステルカラーにして。
背景はうすいピンクにしたい。
```

**フォントを変えたい時：**
```
フォントをもっと丸っこくてかわいい感じにして。
```

**レイアウトを変えたい時：**
```
ゲーム一覧を横並びのカード形式にして。
スマホで見た時は縦に並ぶようにして。
```

**画像を入れたい時：**
```
ここにこの画像を表示して。画像ファイルは images フォルダに入れてあります。
```

### コツ：感覚的に伝えてOK

「なんかダサい」「もうちょっとシュッとして」「ここ気持ち悪い」

こういう曖昧な指示でも、AIはちゃんと汲み取ってくれます。プロのデザイナーに頼むより気軽に言えるのがAIの良いところです。

---

## Step 4：ゲームを作って載せる

サイトだけでなく、ゲーム自体もClaude Codeで作れます。

### ゲーム制作のプロンプト例

**シンプルなゲームを作る時：**
```
ブラウザで遊べるシンプルなゲームを作って。

ゲーム名：かにかにパニック！
内容：30秒間で画面に出てくるカニを叩くゲーム
操作：クリックまたはタップ
スコア表示あり
```

**脱出ゲームを作る時：**
```
ブラウザで遊べる脱出ゲームを作って。

部屋の中にあるアイテムを集めて謎を解いてドアを開ける。
部屋はかわいい雰囲気にして。
アイテムは5個くらい。
```

ゲームも「作って」「ここ変えて」の繰り返しで完成します。

---

## Step 5：サイトを公開する

作ったサイトを世界に公開します。**無料です。**

### GitHub Pagesで公開する手順

Claude Codeにこう伝えてください：

```
このサイトをGitHub Pagesで無料で公開したい。
手順を1つずつ教えて。私はGitHubを使ったことがありません。
```

AIが手順を教えてくれます。基本的にはAIの指示に従ってボタンを押していくだけです。

公開されると、`https://あなたの名前.github.io/サイト名/` というURLでアクセスできるようになります。

---

## 困った時の万能プロンプト集

制作中に困ったら、以下をそのまま使ってください：

**エラーが出た時：**
```
エラーが出ました。何が起きているのか小学生でもわかるように説明して、直してください。
```

**何を言っているかわからない時：**
```
今の説明が全くわかりません。専門用語を使わないでもう一度説明してください。
```

**やり直したい時：**
```
さっきの変更、元に戻して。
```

**完成度を上げたい時：**
```
プロが作ったサイトみたいに見えるように、細かい部分を改善して。
```

**スマホ対応したい時：**
```
スマホで見た時にきれいに表示されるようにして。
```
