## 本文（英語版）

```
THE MACHINE is a short, meta WarioWare-style game made for Gamedev.js Jam 2026 (Theme: Machines).

━━ WHAT YOU THINK IT IS ━━
You are a pilot. You boarded a fighting machine. You will destroy the enemy.

━━ WHAT IT ACTUALLY IS ━━
A reflection on how mechanically we obey instructions we never read.

━━ FEATURES ━━
- 3-act structure with a hidden true theme
- 18 micro-games (each 2-4 seconds)
- 5 branching endings based on how you play
- Ghost replay of your own inputs in Act 3
- Click heatmap visualization
- 9 procedurally generated BGM tracks (all in the same key, all leading to one finale)
- Japanese / English support
- ~5 minutes per playthrough

━━ TIP ━━
Not every instruction is meant to be obeyed.

━━ CREDITS ━━
Gameplay & Audio: Claude (AI) & developer
Art: developer
Engine: Vanilla JavaScript + Canvas
BGM: Web Audio API (procedural)

Made for Gamedev.js Jam 2026
Theme: Machines
```
