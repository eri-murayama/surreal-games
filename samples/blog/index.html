暮らしとおでかけのメディア

日常のなかにある小さな幸せ、週末のおでかけ、季節の食卓。soramameは、写真と文章の温度感をそろえながら「ちょっといい毎日」を見つけるためのライフスタイルメディアを想定しています。

Editorial Note

記事の雰囲気は、テーマごとの写真と切り口で差が出る。

メディアサイトは一覧デザインだけ整えても単調になりやすいので、カテゴリごとにどんな写真と文章が入るのかを想像できることが大事です。旅、食、暮らしでトーンが少しずつ違うと読みたくなります。

この媒体で見せたい切り口

Travel有名スポットより、歩いて気づいた景色を拾う
Foodレシピだけでなく、食べる時間の雰囲気まで書く
Lifestyleすぐ真似できる小さな工夫を中心にする
Interior広い部屋より、現実的なサイズ感の工夫を見せる

編集まわりであると助かる情報

  • 各カテゴリのトーンをひとことで定義しておく
  • 記事タイトルは長くても、読後のイメージが浮かぶ言葉にする
  • 一覧用のアイキャッチは縦横比をそろえると運用しやすいです

Project Note

メディアサイトとして依頼するときの目安

読み物系のサイトは、記事の一覧性、カテゴリ分け、アイキャッチ写真、更新しやすさが大事です。世界観だけでなく、あとから記事を増やしていける設計にしておくと運用が楽になります。

想定する依頼内容

トップ、カテゴリ導線、特集、プロフィール、ニュースレター導線までを含むメディアサイトの入り口ページ。オウンドメディアの雰囲気づくりに向いた構成です。

目安金額16万〜26万円
制作期間3〜5週間
必要素材カテゴリ設計 / 記事見出し / アイキャッチ
写真の目安記事用画像10枚前後 + プロフィール1〜2枚

先にあると進めやすいもの

  • 誰に向けた媒体かをひとことで言える状態にする
  • カテゴリは多すぎないほうが一覧が見やすくなります
  • 記事タイトルは短めでも切り口が見えると印象に残りやすいです
