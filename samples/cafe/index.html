Concept

コンセプト

「珈琲と時間」は、自家焙煎にこだわった24席の小さなカフェです。毎朝焼き上げるスイーツと、香りの立つドリップコーヒーを用意し、近所の方が朝に立ち寄る時間も、仕事の合間にひと息つく午後も、気持ちよく過ごせる空間を目指しています。忙しい日常から少しだけ離れて、自分のペースを取り戻せる時間を届ける想定です。

Project Note

このサンプルを実案件に置き換えると

個人店や新規オープンのカフェでは、世界観と営業情報の両方が必要です。写真で空気感を伝えつつ、営業時間、席数、メニュー、アクセスを迷わず見つけられる構成が向いています。

想定する依頼内容

トップ、コンセプト、メニュー、店内写真、アクセスまでをまとめた1ページ店舗サイト。Instagramへの導線と営業情報の更新しやすさを重視する前提です。

目安金額10万〜14万円
制作期間2〜3週間
必要ページ1ページ + メニュー導線
写真の目安店内外6〜10枚 / メニュー5枚前後

先にあると進めやすい素材

  • 営業時間、定休日、住所、席数、支払い方法
  • 外観、カウンター、テーブル席、看板、人気メニューの写真
  • ロゴがなくても、店名表記とトーンの希望があれば進行できます

掲載文のイメージ

見出し例: 朝の一杯が、今日を少し整える。 紹介文例: 自家焙煎の豆と焼きたてのお菓子を、静かな音楽と一緒に用意しています。 案内文例: 平日 7:00-18:00 / 土日祝 8:00-19:00 / 水曜定休
写真が少ない場合は、外観1枚、店内2枚、看板1枚、メニュー3枚くらいからでも組み始められます。
