# シュールゲームス - フォルダ構成

## よく使うフォルダ

| フォルダ | 内容 |
|---------|------|
| `guppyon/` | ぐっぴょん学園（子供向け知育ゲームサイト） |
| `itch/` | itch.io 配布用ファイル・zip |
| `plicy/` | PLiCy 配布用ファイル・zip |
| `videos/` | 紹介動画（mp4） |

## サイト関連

| フォルダ・ファイル | 内容 |
|-------------------|------|
| `index.html` | トップページ |
| `achievements.html` | 実績ダッシュボード |
| `characters.html` | キャラクター紹介 |
| `prototypes.html` | プロトタイプ一覧 |
| `games/` | ゲーム本体（各ゲームごとにサブフォルダ） |
| `css/` | サイト共通CSS |
| `js/` | サイト共通JS |
| `assets/` | 画像素材 |
| `data/` | お知らせJSON等 |

## その他

| フォルダ | 内容 |
|---------|------|
| `drafts/` | note記事の下書き |
| `tools/` | OGP生成・サムネイル作成・PV書き出し等のツール |
