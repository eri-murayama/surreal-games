# plicy投稿ガイド

## タイトル
**かいだんマインスイーパー**

## キャッチコピー（短い説明）
怪談を聞きながら地雷を探せ。クリアしても、本当の恐怖はこれからだ。

## ジャンル
パズル

## 対応プラットフォーム
- ブラウザ（PC・スマホ両対応）
- タッチ操作対応（長押しで旗、タップで開く）

## タグ候補
マインスイーパー, パズル, ホラー, 怪談, おばけ, 成仏, シュール, スマホ対応, 短時間, カジュアル

## 説明文（plicyページ用）

怪談を聞きながらマインスイーパーで遊ぶ、ちょっと怖い（？）パズルゲームだよ！

👻 **不気味なBGM** と **怪談ボイス** が流れる中で地雷を探せ！
💣 **3つの難易度**: 初級（9x9）/ 中級（16x16）/ 上級（16x30）
🚩 **旗モード**搭載 — タップで旗を切り替え、長押しでも旗を立てられる
🙏 クリアすると **おばけが成仏** する感動（？）の演出
👑 難易度ごとに **最速記録** を保存！自己ベストを目指せ
🎵 Web Audio APIで生成する **こわ〜いBGM**（ドローン音・きしみ音・風の音）

地雷を全部見つけておばけを成仏させよう！
...でも呪われたらゲームオーバー💀

**操作方法**
- タップ / 左クリック: マスを開く
- 長押し / 右クリック: 旗を立てる
- 🚩ボタンで旗モード切り替え（タップで旗を立てられるようになる）
- 👻ボタンでリセット

**プレイ時間**: 1ラウンド1〜15分

## サムネ画像
- ゲーム盤面のスクリーンショット（ダークな雰囲気が伝わるもの）

## 背景画像
- 推奨サイズ: 任意（plicyの仕様に合わせて）
- ダークな紫〜黒の背景に👻を散りばめたイメージ

## アップロード設定
- **画面サイズ目安**: 480 x 750（縦長）
- **モバイル対応**: あり
- **言語**: 日本語のみ
